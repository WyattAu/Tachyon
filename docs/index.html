Tachyon.

Deterministic, high-performance knowledge management system built with Rust.

GitHub Repository Documentation

Features

A complete knowledge management platform with modern capabilities.

Markdown-First Editing

Full CommonMark and GFM support with KaTeX math rendering and syntax highlighting out of the box.

Real-Time Collaboration

CRDT-based conflict resolution via Yrs with WebSocket relay for seamless multi-user editing.

Full-Text Search

Tantivy BM25 ranking combined with PostgreSQL tsvector for fast, accurate search across all content.

Role-Based Access Control

Fine-grained permissions with comprehensive audit logging for team and enterprise environments.

Static Site Generation

Internationalization, RSS feeds, sitemaps, and SEO optimization built into the build pipeline.

Plugin System

WASM sandboxed plugins via Wasmtime for safe, portable extensibility without compromising security.

Multi-Platform Targets

Desktop, web, and CLI deployment from a single codebase with native performance on each platform.

Offline-First Architecture

Local-first data with a persistent sync queue that reconciles changes when connectivity is restored.

Architecture

Three-tier architecture designed for performance and reliability.

Quick Start

Get up and running in under a minute.

Install via Cargo

$ cargo install --git https://github.com/WyattAu/Tachyon tachyon-cli
$ tachyon init my-wiki
$ tachyon serve

Run with Docker Compose

$ git clone https://github.com/WyattAu/Tachyon.git
$ cd Tachyon
$ docker compose up -d

Develop with Nix

$ nix develop
$ cargo build --manifest-path tachyon/Cargo.toml
$ cargo test --manifest-path tachyon/Cargo.toml
