## What is Tachyon?

Tachyon is a deterministic, high-performance documentation engine that operates directly on your file system or Git repository. Unlike traditional static site generators, Tachyon eliminates build steps by providing instant rendering as you edit.

### Key Benefits

- **Local-First**: Full offline functionality with Git-based version control
- **Real-Time**: Sub-15ms rendering latency for instant feedback
- **Cross-Platform**: Native desktop apps for Windows, macOS, and Linux
- **Collaborative**: Server mode for team documentation portals
- **Secure**: Role-based access control and block-level redaction

### Operation Modes

1. **Desktop Mode**: Local-first application for personal knowledge management
2. **Server Mode**: Centralized documentation portal for teams
3. **Static Export**: Generate static HTML for deployment anywhere
